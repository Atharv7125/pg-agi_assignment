# 🤖 TalentScout AI Hiring Assistant

## 1. Project Overview

This project is an intelligent AI Hiring Assistant chatbot created for "TalentScout," a fictional recruitment agency. The chatbot is designed to conduct the initial screening of candidates by gathering essential information and posing relevant technical questions based on the candidate's declared tech stack.

The application is built using Python and Streamlit, with Google's Gemini Pro LLM as its conversational engine.

### Key Features:
- **Interactive Chat Interface:** A clean and user-friendly UI built with Streamlit.
- **Structured Conversation Flow:** A robust state machine guides the conversation from greeting to completion.
- **Dynamic Progress Bar:** A sidebar provides real-time feedback on screening progress.
- **Input Validation:** Ensures that inputs like email, phone number, and years of experience are in the correct format.
- **AI-Powered Question Generation:** Technical questions are dynamically generated by an LLM based on the candidate's specific tech stack.
- **Data Persistence:** All successfully collected candidate information is saved to a local `candidate_data.csv` file for review.

## 2. Installation Instructions

To set up and run this application locally, please follow these steps:

**Prerequisites:**
- Python 3.8+
- Git

**Steps:**
1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/your-repo-name.git)
    cd your-repo-name
    ```

2.  **Create and activate a virtual environment:**
    ```bash
    # For Windows
    python -m venv venv
    venv\Scripts\activate

    # For macOS/Linux
    python -m venv venv
    source venv/bin/activate
    ```

3.  **Install the required libraries:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Set up your API Key:**
    - Create a `.env` file in the root of the project directory.
    - Add your Google Gemini API key to the file as follows:
      ```
      GOOGLE_API_KEY="YOUR_API_KEY_HERE"
      ```
